# Study-AI

Study-AI is an AI-powered web application designed to enhance student learning by transforming notes and lectures (PDFs, audio, or text) into summaries, flashcards, quizzes, and providing a conversational AI tutor for interactive topic discussions.

---

## Features

- Upload lecture audio, PDFs, or text notes  
- Generate instant summaries, flashcards, and quiz questions  
- Chat with an AI tutor about any topic  
- Track learning progress and identify weak areas  

---

## Technology Stack

- **Frontend:** React with Vite, Zustand for state management, React Router for routing, Tailwind CSS for styling  
- **AI/NLP:** Whisper for audio transcription, Groq AI for summarization, flashcards, and Q&A  
- **File Uploads:** React Dropzone
